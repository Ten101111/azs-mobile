# Свод аналитики: состав показателей и настраиваемая панель

Вопрос №9 реестра открытых вопросов. Источники отбора:
«Витрина данных - описание.xlsx» (61 позиция) и «Приоритезация данных по этапам v1.xlsx»
(115 показателей × представлений, из них 33 — Этап 1; лист «Функционал» — 14 задач по этапам).

## 1. Решения, которые зафиксированы

1. Свод — **настраиваемая панель**. Состав плиток — данные, а не код: каталог ведётся администратором.
2. В MVP в каталог включаются **только показатели, которые сегодня считаются из витрины**.
3. **Нет данных — нет плитки.** Показатель, источника которого нет в витрине текущего этапа,
   не отображается и не предлагается в каталоге. Пустых и «серых» плиток не бывает.
   По мере расширения витрины плитки добавляются администратором.
4. Для **агентов** — отдельный шаблон свода.
5. **Качество сервиса (КС)** включено в MVP для агентов: в приоритезации показатель отнесён к Этапу 2,
   но все четыре компонента формулы присутствуют в витрине уже сейчас. Подтверждено владельцем.
6. Премиальная панель (свод из показателей, формирующих рейтинг) — **концепция целевого этапа**,
   раздел 6 настоящего документа. В MVP не реализуется: части источников в витрине нет.
7. Показатели следующих этапов разложены по группам в разделе 7 — каталог пополняется по мере
   появления источников, поштучно, без доработки приложения.

## 4. Требования к настраиваемой панели

| ID | Требование |
|---|---|
| БТ-СВ1 | Каталог плиток — системный справочник: идентификатор, наименование, группа, единица, формула, перечень источников в витрине, допустимые представления, уровни применимости (сеть / ОНПО / РУ / территория / объект) |
| БТ-СВ2 | Плитка доступна, только если **все** её источники присутствуют в витрине текущего этапа. Недоступная плитка не отображается и не предлагается в каталоге |
| БТ-СВ3 | Администратор задаёт шаблон свода по умолчанию для каждой роли; шаблон для агентов ведётся отдельно от шаблона управленческой вертикали |
| БТ-СВ4 | Пользователь настраивает свою панель: включает, выключает и переставляет плитки в пределах каталога, разрешённого его роли; действие «Сбросить к шаблону роли» возвращает состав по умолчанию |
| БТ-СВ5 | Администратор может пометить плитку шаблона как закреплённую — пользователь не вправе её убрать |
| БТ-СВ6 | Количество плиток свода — от 4 до 8, значение по умолчанию 6; границы настраиваются администратором |
| БТ-СВ7 | Представления плитки: абсолют; выполнение плана (только если план доведён); динамика к аналогичному периоду прошлого года; позиция среди сопоставимых объектов (только если бенчмарк применим) |
| БТ-СВ8 | Период: текущий месяц — скользящим MTD против аналогичного отрезка прошлого года; завершённые месяцы — целиком |
| БТ-СВ9 | Настройка состава не влияет на права: агрегаты рассчитываются строго в пределах области данных роли |
| БТ-СВ10 | При расширении витрины новые показатели вводятся в каталог администратором без доработки приложения |
| БТ-СВ11 | Персональная настройка хранится за пользователем и переживает смену шаблона роли; при удалении плитки из каталога она молча исчезает из персональных наборов |

## 6. Целевая концепция: свод как премиальная панель (будущие этапы)

Замысел: свод показывает ровно те показатели, из которых складывается рейтинг и премия,
в той же формулировке и с теми же порогами, что в нормативной методике. Тогда справки,
аналитика и премирование говорят на одном языке, и вопрос «почему у меня такой рейтинг»
закрывается самой панелью.

Целевой состав и готовность источников:

| Плитка | Раздел методики | Источник |
|---|---|---|
| Реализация топлива, % плана | 8 | есть (витрина 6, 19, 20) |
| НТУ, % плана | 7 | есть (витрина 28, 39) |
| Уровень сервиса | 4 | есть (витрина 45–50) + справочник целей |
| Качество сервиса | 9 | есть (витрина 43, 46, 47, 21) |
| Соблюдение стандартов обслуживания | 5 | **источника нет** |
| Списание продукции кафе | 3 | **источника нет**, Этап 2 |

Дополнительно на целевом этапе: расчёт набранных баллов рейтинга и остатка до следующего
порога, с расшифровкой вклада каждого показателя.

Плитки вводятся по мере появления источников — поштучно, через каталог (БТ-СВ2, БТ-СВ10).
Дожидаться полного комплекта не требуется.

Функциональные этапы из листа «Функционал» того же файла: Этап 2 — каналы реализации
(ФЛ с картой, ФЛ без карты, ЮЛ), графики и таблицы в отчётности; Этап 3 — детализация до СКЮ,
BI-отчётность и текстовые источники, презентации; Этап 4 — анализ эффективности промоакций,

Они определяют не состав свода, а глубину разрезов и форматы вывода.

**Что важно для премиальной панели.** Из шести её плиток пятая — «Списание продукции кафе» —
появляется вместе с группой «Списания и потери» Этапа 2. Шестая, **«Соблюдение стандартов
обслуживания», не значится ни в Этапе 1, ни в Этапе 2 приоритезации** — источника в дорожной
карте витрины нет вообще. Его нужно заводить отдельным требованием (В-10), иначе премиальная
панель не собирается даже на целевом этапе.

## 9. Что уже собрано в прототипе

Раздел «Аналитика → Свод». Каталог плиток объявлен декларативно: у каждой плитки
перечислены столбцы витрины, без которых она невозможна, и правило «нет данных —
нет плитки» соблюдается само, а не пометками вручную. Одна и та же плитка имеет
определения под разные витрины (ОХД и демонстрационный стенд), поэтому
пользовательские наборы переносятся между контурами без правок.

| Требование | Состояние | Как реализовано |
|---|---|---|
| БТ-СВ1 | Выполнено | Каталог плиток в коде: идентификатор, наименование, группа, единица, выражение, перечень источников, знаки после запятой, подсказка, направление «больше — лучше / меньше — лучше» |
| БТ-СВ2 | Выполнено | Доступность считается по фактическому составу столбцов каталога витрины; недоступная плитка не показывается и не предлагается в настройке |
| БТ-СВ3 | Частично | Шаблон управленческой вертикали и отдельный шаблон агента заданы; редактирования шаблонов администратором в интерфейсе пока нет |
| БТ-СВ4 | Частично | Включение и выключение плиток, «Вернуть состав по умолчанию» — есть; перестановка плиток мышью — нет |
| БТ-СВ5 | Не начато | Закреплённые плитки |
| БТ-СВ6 | Выполнено | Границы 4–8 проверяются и на клиенте, и на сервере |
| БТ-СВ7 | Частично | Абсолют, выполнение плана и динамика год к году — есть; позиция среди сопоставимых объектов — нет |
