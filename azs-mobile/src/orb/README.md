# Орб «Мобильного аналитика»

Порт «Recursive Erosion» (Meng To, ThreeUI, лицензия MIT) — частичная сфера
из 2500 точек, которую мнёт симплекс-шум, выедает эрозия и по которой ползут
светящиеся трассы, — переведённый в корпоративные цвета и посаженный на
машину состояний. Решение владельца от 22.09.2026: «точь-в-точь как референс,
только в наших цветах». Геометрия, шум, черви, проходы — дословно из исходника;
изменены палитра (оранжевая → красная #E31E24), убрана подпись-бейдж, а константы
(порог эрозии, амплитуда, сила трасс, скорость, яркость) стали пружинными
параметрами состояний.

## Файлы

| Файл | Что это |
|---|---|
| `orbEngine.js` | Движок без зависимостей: WebGL1, шейдеры частиц, пружины параметров, машина состояний, DPR, reduced-motion, demo |
| `orbEngine.sdf.legacy.js`, `orbShader.sdf.legacy.js` | Предыдущая версия (SDF-орб с кольцом и столбцами) — хранится для истории, не подключена |
| `AiOrb.jsx` | React-обёртка: пропс `state`, подпись на Framer Motion, запасной рендер без WebGL, `orbStateFromPipeline()` |
| `demo.html` | Страница с переключателями состояний и demo-циклом (открывать через Vite или любой статический сервер) |

## Состояния

`idle · listening · searching · analyzing · forming · ready` — из брифа,
плюс два исхода приложения: `refused · error`.

## Использование

```jsx
import AiOrb, { orbStateFromPipeline } from "./orb/AiOrb.jsx";

<AiOrb state={orbStateFromPipeline({ typing, pending, stages, outcome })} size={240} label />
```

Без React:

```js
import { createOrb } from "./orb/orbEngine.js";
const orb = createOrb(canvas, { tapToListen: true });
orb.setState("analyzing");
orb.demo.start();
```

## Что учесть при интеграции

- Холст рисует только пока виден (IntersectionObserver) и вкладка активна.
- `quality: "auto"` даёт DPR ≤ 1.5 на телефоне и ≤ 2 на десктопе; частиц всегда 2500 — это дёшево.
- Частицы живут на чёрном: в приложении у холста своя тёмная круглая сцена (`.ai-orb canvas` в styles.css).
- При `prefers-reduced-motion` петля стоит на кадре 1,2 с (как в оригинале); смена состояния перерисовывает кадр один раз.
- Без WebGL2 компонент рендерит `fallback` — передайте туда `<AiMark />` из приложения.
