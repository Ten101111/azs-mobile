# Справочник сокращений и терминов проекта

Версия 1.0 · 21 сентября 2026 г. · владелец — А. А. Манохин
Назначение: один источник расшифровок для БТ, макетов справок, базы знаний и контекста
ИИ-аналитика. Блок J эталонного набора вопросов проверяет модель именно по этому списку.

**Правило работы с сокращением.** Сокращение из раздела 2 модель понимает без переспроса
и отвечает по существу. Сокращения, которого в справочнике нет, модель не расшифровывает
по догадке: она говорит, что такого показателя не знает, и просит уточнить. Придуманная
расшифровка хуже переспроса — на ней строится число, которое потом никто не проверит.

---

## 1. Как пополнять

Справочник ведёт владелец продукта. Новая строка появляется, когда сокращение впервые
встречается в нормативном документе, витрине или постановке — вместе со ссылкой на
источник. Удалять строки нельзя: сокращение, вышедшее из употребления, помечается
как устаревшее, иначе старые документы перестают читаться.

| АЗС | Автозаправочная станция | Везде |
| АУП | Административно-управленческий персонал | Ролевая модель: АУП сети, АУП ОНПО |

| ВП | Валовая прибыль | Приоритезация данных, Этап 2 |
| ДТ | Дизельное топливо | Витрина: `sum_weight_dt`, `sum_volume_dt` |
| ЕГЛ | Единая горячая линия | Витрина: `cnt_num_compl` — жалобы ЕГЛ; показатель «Качество сервиса» |
| КЛ | Карта лояльности | Витрина: `cnt_cheq_kl` — чеки с картой лояльности |

| ЛИКАРД | ООО «ЛИКАРД» — оператор программы лояльности и расчётов | Источник оценок, отчёт по уровню сервиса |

| НПО | Нефтепродуктообеспечение | Название отрасли и вид деятельности общества |
| НТ | Нетопливные товары | Приоритезация данных: списания НТ, поставка НТ |

| ОНПО | Организация нефтепродуктообеспечения — общество сети | Ролевая модель, область данных |

| ПСИ | Приёмо-сдаточные испытания | План внедрения |

| СКЮ, SKU | Товарная позиция номенклатуры | Витрина: `sum_quant_cafe`, `sum_quant_prod`, `sum_quant_neprod` |

## 3. Пары, которые чаще всего путают

| Пара | Чем различаются |
|---|---|
| **УС и КС** | УС — уровень сервиса: средняя оценка к цели, чем больше, тем лучше, адресаты — РУ, ТМ, менеджеры комплексов, работники АЗС. КС — качество сервиса: негатив и жалобы на 100 тыс. чеков, чем меньше, тем лучше, адресаты — агенты и заправщики. Это разные показатели с разными формулами; подменять один другим нельзя |
| **ВД и выручка** | Выручка НТУ — `sum_receipt_netto_ntu`, без НДС. ВД НТУ — `vd_ntu`, выручка за вычетом себестоимости. Маржа НТУ — ВД к выручке |
| **НТУ и НТ** | НТУ — нетопливные товары и услуги, показатель витрины Этапа 1. НТ — нетопливные товары в узком смысле, встречается в позициях Этапа 2 (списания, поставки) |
| **Чеки** | `cnt_cheq` — все уникальные чеки. `cnt_cheq_tu` — топливные. `cnt_cheq_ntu` — с нетопливной покупкой. `cnt_complex_cheq_tu_ntu` — комплексные. Конверсия считается как НТУ-чеки к топливным |
| **КССС и номер АЗС** | КССС (`ksss_azs_code`) — внутренний код, номер (`num_azs`) — цифры на вывеске. У одной станции это разные числа. Когда объект назван просто числом, фильтровать нужно по обоим полям |
| **Количество товаров: ретейл и баланс** | `sum_quant_ntu_retail` — учёт по ретейлу, используется в расчётах по решению владельца от 20.09.2026. `sum_quant_ntu_balance` — учёт по балансу, в расчётах не применяется до подтверждения соотношения |
| **Оценка «3»** | В расчёте средней участвует как 3 балла, но негативной в правиле автоматического выполнения не считается: негатив — только «1» и «2» |

## 4. Слова, которых в продукте нет

| Не используем | Используем | Почему |
|---|---|---|
| Кластер аналогов, кластер | Группа сопоставимых АЗС | Слово «кластер» в методике занято: так называется группа АЗС под управлением агента и группа рейтинга качества сервиса. Решение владельца №32 |
| Рейтинг АЗС | Позиция в группе сопоставимых АЗС | «Рейтинг» в методике — основание для премирования, это другой объект |
| Оценка сотрудника | Результат руководителя | Линейный персонал в продукте не оценивается: данных нет, класс К13 закрыт |

## 5. Правила для ИИ-аналитика

1. Сокращения раздела 2 понимаются без переспроса и без расшифровки в ответе, если
   пользователь сам написал сокращённо.
2. Сокращение вне справочника — прямой ответ «такого показателя не знаю» и просьба
   уточнить. Расшифровка по созвучию запрещена.
3. При первом употреблении в длинном разборе сокращение раскрывается один раз,
   дальше используется коротко.
4. Термины раздела 4 не употребляются ни в каком виде, даже если так спросил пользователь;
   в ответе используется правильный термин.
5. Пары раздела 3 не смешиваются: если из вопроса неясно, какой показатель имеется в виду,
   ИИ называет, какой взял, и предлагает второй.
