# Сценарий демонстрации приложения «Классификатор АЗС»

Порядок повествования для живого показа: в левой колонке — что нажимаем и показываем на экране, в правой — подстрочник (текст, который проговариваем параллельно). Общий хронометраж — примерно 12–15 минут. Перед демонстрацией: запустить `./start_app.command`, открыть `http://localhost:5174/`, проверить, что данные (`stations.json`) подготовлены и ключ Яндекс Карт активен.

---

## 0. Вступление (30 сек)

| Действие на экране | Подстрочник |
|---|---|
| Экран входа открыт, ничего не нажимаем | «Я покажу мобильное приложение — единый рабочий контур по сети АЗС. Внутри: реестр всех объектов, карта, паспорт каждой станции с контактами и сервисами, показатели месяца, рекомендации по персоналу, аналитика и контроль качества данных. Приложение работает как PWA — его можно установить на телефон как обычное приложение». |

## 1. Авторизация и защита доступа (1–1,5 мин)

| Действие на экране | Подстрочник |
|---|---|
| Показываем экран входа, обращаем внимание на заголовок «Корпоративный доступ» и блок «Только для сотрудников компании» внизу | «Приложение закрыто корпоративной авторизацией. Войти могут только сотрудники: система проверяет домен почты и allowlist. Внешний email не пройдёт ни регистрацию, ни вход — и реестр, и карта, и API без сессии недоступны». |
| Переключаем вкладки «Вход» / «Регистрация», показываем поля Имя, Email, Пароль | «Здесь два режима: вход и регистрация. При регистрации указываем имя, корпоративную почту и пароль от восьми символов». |
| Вводим email и пароль, нажимаем «Войти» (или «Создать доступ»). Если требуется — показываем экран «Подтвердите email» и вводим код | «При первой авторизации на корпоративную почту приходит одноразовый код — без подтверждения сессия не создаётся. Код можно запросить повторно или поменять email». |
| (Опционально) Нажимаем «Забыли пароль?» и показываем форму восстановления, затем возвращаемся кнопкой «Вернуться ко входу» | «Восстановление пароля тоже через код на корпоративную почту: вводим email, получаем код, задаём новый пароль». |
| Завершаем вход — открывается Главная | «Входим — и попадаем сразу в рабочий режим, без промо-экранов». |

## 3. Реестр: поиск и фильтры (2–2,5 мин)

| Действие на экране | Подстрочник |
|---|---|
| Нажимаем «Реестр» (внизу или на главной) | «Переходим в реестр — это основной список всех АЗС с координатами». |
| Показываем шапку: счётчик «N на карте · скрыто M» | «В шапке — сколько объектов в работе и сколько скрыто без координат». |
| Кликаем в строку поиска, вводим номер АЗС / КССС / город | «Поиск работает по всему сразу: КССС, номеру станции, названию, адресу, региону и городу. Начинаем вводить — список и счётчики пересчитываются мгновенно, всё уже закэшировано локально». |
| Нажимаем крестик — очищаем поиск | «Одним нажатием сбрасываем». |
| Показываем метрики над списком: Найдено, Действующих, Кафе, С санузлом | «Эти четыре счётчика всегда показывают срез по текущему поиску и фильтрам». |
| Прокручиваем ленту быстрых фильтров, открываем по очереди: НПО → Регион → Статус → Тип → Сервис (выбираем, например, «Кафе») | «Быстрые фильтры — прямо над списком: НПО, регион, статус, тип станции и сервисы — магазин, кафе, санузел, знаковые объекты. Выбранный фильтр подсвечивается, значения комбинируются». |
| Нажимаем иконку-слайдеры в правом верхнем углу — открывается нижняя панель фильтров | «Полная панель фильтров открывается снизу, как принято на мобильных. Здесь есть дополнительный фильтр по качеству данных — показать только объекты с замечаниями». |
| Выбираем «Есть замечания», закрываем панель свайпом вниз или крестиком | «Так руководитель за два нажатия получает список проблемных карточек». |
| Нажимаем «Сбросить» в заголовке списка | «Сбросить всё — одна кнопка». |
| Показываем строку списка: цветная точка статуса, название, КССС, адрес, бейджи | «Каждая строка — мини-паспорт: цвет точки — статус (зелёный — действующая, янтарный — консервация, фиолетовый — реконструкция), ниже адрес и бейджи сервисов. Если по объекту есть замечания к данным — жёлтый бейдж с их числом». |
| Переключаем «Подробно» / «Компактно» | «Плотность списка переключается: компактный режим — когда нужно быстро пролистать много объектов». |
| Нажимаем сердечко на строке | «Сердечко — избранное, сохраняется на устройстве: свои объекты всегда под рукой». |

## 4. Карточка АЗС: паспорт объекта (3 мин)

| Действие на экране | Подстрочник |
|---|---|
| Нажимаем на строку в реестре — снизу выезжает карточка | «Нажимаем на станцию — снизу выезжает карточка объекта». |
| Тянем за "грабер" вверх — раскрываем на весь экран; показываем, что свайп вниз сворачивает | «Карточка живёт как шторка: тянем вверх — полный экран, вниз — сворачивается, карта при этом остаётся видна». |
| Показываем шапку карточки: КССС, чип статуса, название, адрес, быстрые факты (регион, НПО, замечания) | «В шапке — всё главное: КССС, статус, адрес и быстрые факты. Сразу видно, есть ли по объекту замечания к данным». |
| Нажимаем сердечко в карточке | «Избранное доступно и отсюда». |
| Показываем кнопку «Позвонить» (не звоним) | «"Позвонить" — набирает первый доступный телефон по цепочке: менеджер станции, старший оператор, ТМ, РУ. С телефона это один тап до звонка». |
| Нажимаем «Яндекс маршрут» — открывается вкладка с маршрутом, возвращаемся | «"Яндекс маршрут" — строит маршрут до станции в Яндекс Картах. Это основной выездной сценарий». |
| Показываем блок «Показатели месяца»: 4 KPI-карточки | «Дальше — показатели текущего месяца: выручка, объём топлива, количество чеков и средний чек. У каждого показателя — динамика к прошлому месяцу и к прошлому году, рост зелёным, падение красным. Подпись под заголовком честно показывает источник: боевые данные из БД или демо-заглушка до подключения». |
| Показываем блок «Персонал»: сводка и календарь; листаем календарь по горизонтали; если периодов несколько — переключаем месяц в селекте | «Блок "Персонал" — рекомендации по сменам на каждый день месяца: сколько человек нужно днём и ночью. Календарь сам проматывается к сегодняшнему дню, месяцы переключаются. Рекомендации считаются из месячных Excel-файлов по нормо-часам». |
| Раскрываем секцию «Основное» | «Ниже — паспорт объекта раскрывающимися секциями. Основное: КССС, номер, статус, тип, НПО, регион, город, координаты». |
| Раскрываем «Классификация», показываем бейджи | «Классификация: формат, формат второго уровня, Minale, локация, окружение — и признаки: действующая, агентская схема, Ликард, Тебойл, MD». |
| Раскрываем «Сервисы» | «Сервисы наглядно: магазин, кафе, санузел, знаковый проект — активные подсвечены, с примечаниями. Ниже сервисный кластер и уровни LukCafe». |
| Раскрываем «Ответственные», нажимаем на телефон одного из контактов (показываем, не звоним) | «Ответственные: РУ, ТМ, менеджер, старший оператор — каждый телефон кликабелен, звонок в одно нажатие». |
| Раскрываем «Инфраструктура» | «Инфраструктура: количество ТРК и постов, площади торгового зала и операторной, тип оплаты». |
| Раскрываем «Трасса и история» | «Трасса: федеральная ли, номер и наименование, плюс дата изменения данных и комментарии». |
| Если есть — показываем жёлтую секцию «Качество данных» | «И если в данных есть пробелы — отдельная жёлтая секция перечисляет замечания. Они не мешают просмотру, но их видно». |
| Свайпаем карточку вниз — закрываем | «Закрываем — возвращаемся к списку». |

## 5. Карта (1,5–2 мин)

| Действие на экране | Подстрочник |
|---|---|
| Нажимаем «Карта» в навигации | «Второй способ смотреть сеть — карта. Здесь все объекты с валидными координатами». |
| Показываем шапку карты: «N точек на карте» | «Счётчик точек синхронен с фильтрами: отфильтровали кафе в реестре — на карте останутся только они». |
| Отдаляем масштаб — показываем кластеры, приближаем — кластеры рассыпаются | «При отдалении маркеры собираются в кластеры с числом объектов — карта не превращается в кашу даже на всей стране. Приближаем — кластеры рассыпаются на точки». |
| Показываем легенду в углу карты | «Цвет маркера — статус: зелёный — действующая, янтарный — консервация, фиолетовый — реконструкция, оранжевый — оптимизация». |
| Нажимаем на маркер — снизу поднимается карточка станции | «Нажатие на маркер открывает ту же карточку объекта — со звонком, маршрутом, KPI и персоналом. Выбранная станция подсвечивается красным». |
| Нажимаем кнопку геолокации (прицел) в шапке карты | «Кнопка геолокации определяет, где я нахожусь — сначала через Яндекс, при неудаче через браузер, — ставит синюю метку "Вы здесь", а главное — сама находит и открывает ближайшую АЗС с расстоянием до неё. Это сценарий выезда: приехал в район — сразу видишь свою станцию». |
| Показываем тост «Ближайшая АЗС: … · N км» | «Вот подсказка: ближайшая станция и дистанция». |

## 6. Аналитика (3 мин)

### 6.1. Вкладка «Обзор»

| Действие на экране | Подстрочник |
|---|---|
| Нажимаем «Аналитика» в навигации | «Раздел аналитики. Важно: он считает по текущей выборке — фильтры из реестра действуют и здесь. В шапке видно: сколько объектов из скольких попало в срез». |
| Показываем KPI-плитки: Действующие, С магазином, С кафе, С санузлом, Замечания, Знаковые, Агентская схема | «Верхний ряд — ключевые доли сети: действующие, сервисное покрытие — магазины, кафе, санузлы, — замечания по данным, знаковые проекты и агентская схема. Каждая плитка — число и процент выборки». |
| Прокручиваем диаграммы: Статусы, НПО, Форматы, Регионы, Локация | «Ниже — распределения: по статусам, по НПО, по форматам, топ регионов и локация. Это ответ на вопрос "как устроена сеть" за один экран». |
| Нажимаем в карточке «Качество данных» кнопку «Есть замечания» — приложение переходит в Реестр с включённым фильтром | «Аналитика связана с реестром: нажимаю "Есть замечания" — и получаю готовый список проблемных объектов». Возвращаемся в Аналитику. |

### 6.2. Вкладка «Разрезы»

| Действие на экране | Подстрочник |
|---|---|
| Нажимаем вкладку «Разрезы», переключаем сегменты ТМ → РУ → АЗС | «"Разрезы" — управленческая таблица за месяц: выручка, топливо и чеки, сгруппированные по территориальным менеджерам, региональным управляющим или отдельным станциям. У каждой строки — динамика месяц к месяцу и год к году, и полоска-рейтинг по выручке». |

### 6.3. Вкладка «Похожие»

| Действие на экране | Подстрочник |
|---|---|
| Нажимаем «Похожие» — приложение само определяет ближайшую АЗС (показываем сообщение геолокации) | «"Похожие" — подбор аналогов. Приложение само определило мою ближайшую станцию и взяло её за базу — но базу можно выбрать и вручную». |
| Кликаем в поле, начинаем вводить КССС/адрес — показываем подсказки, выбираем станцию | «Автодополнение ищет по КССС, номеру и адресу». |
| Показываем список похожих: score, причины, метрики | «Для каждой похожей станции — оценка сходства и объяснение, почему она похожа: тот же регион, формат, локация, сопоставимые объёмы. И сразу её показатели месяца». |
| Нажимаем «Открыть» на одной из карточек — открывается карточка станции; возвращаемся | «"Открыть" ведёт в полную карточку объекта». |
| Нажимаем «Сравнить» на другой — переходим на вкладку «Сравнение» с уже добавленной парой | «"Сравнить" — забирает базу и аналог сразу в сравнение». |

### 6.4. Вкладка «Сравнение»

| Действие на экране | Подстрочник |
|---|---|
| Показываем чипы выбранных станций и счётчик «N / 5», добавляем через поиск ещё одну | «Сравнивать можно до пяти станций одновременно. Добавляем через тот же поиск, убираем нажатием на чип». |
| Прокручиваем таблицу сравнения | «Таблица сравнивает всё: регион, РУ и ТМ, формат, локацию, ТРК и посты, штат — и бизнес-метрики: выручку, объём топлива, чеки, средний чек. Это готовый ответ на вопрос "почему одна станция продаёт больше другой"». |

## 7. Контроль: качество данных и обратная связь (1,5 мин)

## 9. Финал: как живут данные (30 сек, словами)

| Действие на экране | Подстрочник |
|---|---|
| Можно вернуться на Главную к плитке «Источник» | «Пару слов про данные. Источник — корпоративная выгрузка Excel: скрипт нормализует её и собирает реестр, дата обновления видна на главной. ## Чек-лист перед показом

- [ ] `./start_app.command` запущен, `http://localhost:5174/` открывается.
