# База знаний проекта «Классификатор АЗС»

Это переносимый контекст проекта для нового Codex, разработчика или владельца продукта. База основана на файлах рабочего каталога на 31.08.2026; она не заменяет первичные документы и не содержит секретов, реальных выгрузок АЗС или учетных данных.

## Как пользоваться

1. Начать с [Состояние проекта](CURRENT_STATE.md): там разделены подтверждённая реализация, цели и ограничения.
2. Затем открыть [Бэклог и решения](ROADMAP.md): приоритеты, открытые вопросы и критерии готовности.
3. При необходимости сверить термины по [глоссарию](GLOSSARY.md).
4. Для нового Codex использовать [стартовый контекст](HANDOFF_PROMPT.md) как первое сообщение и приложить нужные файлы из индекса ниже.
5. При каждом заметном изменении обновлять дату, статус задачи и ссылку на подтверждающий артефакт. Не записывать сюда пароли, токены, персональные данные и приватные выгрузки.

## Правило статусов

- **Подтверждено кодом** — видно в исходниках или тестах.
- **Подтверждено документом** — заявлено в ТЗ/README, но не проверялось в этом обзоре.
- **Частично** — есть основа, но документ прямо описывает незакрытые условия.
- **План** — целевая работа, не считать её реализованной.
- **Нужно решить** — решение или владелец отсутствуют.
