# Глоссарий проекта

| Термин | Значение в проекте |
|---|---|
| АЗС | Автозаправочная станция — основной объект реестра и аналитики. |
| КССС / `ksss` | Уникальный код АЗС, используемый для связи источников. Основной ключ приложения. |
| DWH | Корпоративное хранилище данных PostgreSQL. Не доступно напрямую публичному серверу. |
| KPI | Показатели АЗС: выручка, объём топлива, количество чеков, средний чек, НТУ и др. Формулы подлежат согласованию владельцем данных. |
| MoM | Сравнение с предыдущим месяцем; для неполного периода сопоставляется одинаковое число дней. |
| YoY | Сравнение с аналогичным периодом прошлого года; для неполного периода сопоставляется одинаковое число дней. |
| MTD | Данные с первого дня месяца до последней доступной даты. |
| НТУ | Нетопливные товары и услуги в определённых бизнес-категориях. |
| PWA | Progressive Web App: web-приложение, которое можно установить на домашний экран телефона. |
| API | Программный интерфейс между frontend, backend и внутренними интеграциями. |
| VPN / MobilePass+ | Корпоративный защищённый доступ к DWH с корпоративного устройства; режим постоянной автоматизации не подтверждён. |
| Corporate DWH Agent | Планируемый компонент в корпоративной сети, который инициирует исходящее соединение с очередью и выполняет разрешённые read-only запросы к DWH. |
| AI Worker | Планируемый отдельный узел с локальной языковой моделью. Не размещается на текущем web-VPS. |
| SQL AST Validator | Планируемый детерминированный валидатор структуры SQL, который ограничивает запросы, предложенные LLM. |
| Golden SQL / golden questions | Согласованные эталонные запросы и вопросы для проверки формул и качества AI-ответов. |
| RBAC | Управление доступом по ролям и области данных; в полном виде пока не реализовано. |

Первичный источник определений: [ТЗ v4](../azs-mobile/ТЗ_Классификатор_АЗС_v4.md). Для статуса реализации сверяйтесь с [состоянием проекта](CURRENT_STATE.md).
