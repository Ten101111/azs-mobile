# Стартовый контекст для другого Codex

Скопируйте текст ниже в новый чат Codex вместе с папкой `База_знаний_проекта`.

```text
Ты работаешь с проектом «Классификатор АЗС» в рабочем каталоге. Сначала прочитай:
1) База_знаний_проекта/README.md
2) База_знаний_проекта/CURRENT_STATE.md
3) База_знаний_проекта/ROADMAP.md
4) azs-mobile/ТЗ_Классификатор_АЗС_v4.md — первичная целевая спецификация.

Правила работы:
- Не выдавай требования из ТЗ за реализованный функционал: код является источником истины реализации.
- Не раскрывай и не коммить реальные выгрузки АЗС, персональные данные, пароли, токены, .env.local, SQLite production-базы или DWH-реквизиты.
- Рабочее дерево может быть грязным; сначала посмотри git status и не откатывай чужие изменения.
- Не подключай публичный сервер к корпоративному VPN и не размещай на нём DWH-реквизиты.
- Для AI не предлагай прямой доступ модели к DWH: нужны read-only доступ, allowlist, детерминированный SQL validator и трассируемость.

Текущий запрос пользователя: [вставьте актуальную задачу].
Перед изменениями кратко опиши, какие первичные файлы подтверждают выбранный подход. После изменений добавь запись в базу знаний, если изменились архитектура, статус работ, решения или открытые вопросы.
```

```markdown
### YYYY-MM-DD — краткое название

- **Тип:** решение | реализация | риск | исследование | изменение данных
- **Статус:** подтверждено кодом | подтверждено документом | частично | план | нужно решить
- **Что изменилось:** …
- **Почему:** …
- **Доказательство:** ссылка на файл, тест, PR, тикет или измерение.
- **Следующее действие и владелец:** …
```
